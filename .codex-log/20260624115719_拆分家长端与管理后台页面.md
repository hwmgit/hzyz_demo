# 需求分析

用户要求将家长端和管理后台拆分页面，确保扫码只进入家长端页面，不展示管理页面。

# 方案设计

- `index.html` 改为家长端扫码落地页，只包含身份核验、缴费详情、聚合支付演示和回执。
- 新增 `admin.html` 作为管理后台，包含学生导入/新增、收费配置、缴费状态监控和缴费 URL 分发说明。
- 两页继续不接后端，通过同源 `localStorage` 的 `eduFeeDemoState` 共享假数据，确保后台导入学生后家长端可以核验。
- 扫码二维码应指向 `index.html`，后台页面只供演示人员使用。

# 任务规划
