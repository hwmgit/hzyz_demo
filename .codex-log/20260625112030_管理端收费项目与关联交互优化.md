# 需求分析

本次调整管理端演示能力：

- 收费项目配置增加“新增收费项目”能力。
- 学生班级样例改为继续教育方向。
- 学生关联收费项目支持按班级筛选后批量选择学生。
- 原“清空已关联项目”存在语义歧义，拆分为“移除勾选项目”和“清空所选学生全部项目”两个动作。

# 方案设计

- 保持纯静态 HTML + localStorage 演示架构，不引入构建与网络依赖。
- 新增收费项目默认启用，并进入统一 `feeItems` 数据池。
- 关联页新增班级筛选，只影响批量选择学生区域，不影响学生管理列表。
- 清空类操作与主关联操作分组展示，降低误操作理解成本。

# 代码实现

- `admin.html`：新增收费项目表单、班级筛选下拉、移除勾选项目、清空所选学生全部项目。
- `admin.html`：更新默认学生与导入示例班级为继续教育方向。
- `index.html`：同步更新家长端默认学生班级，保持两端初始数据一致。
- `scripts/validate-demo.mjs`：补充新增项目、班级筛选、拆分按钮和继续教育班级的静态校验。
