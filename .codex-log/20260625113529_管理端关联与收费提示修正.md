# 需求分析

本次修正三个管理端问题：

- 收费项目未填写时点击“新增收费项目”缺少可见提示。
- 学生关联收费项目在按班级筛选后执行批量关联，筛选状态丢失。
- 缴费状态列表在清空关联项目后未正确体现变化。

# 方案设计

- 为收费项目页增加独立提示区，避免错误提示落在其他菜单页面不可见。
- 重绘批量关联区域时保留当前激活页面的班级筛选状态。
- 修正学生费用计算规则：仅当 `feeIds` 缺失时回退到全部启用项目；当 `feeIds` 是空数组时表示明确未关联任何项目。

# 代码实现

- `admin.html`：新增 `feeMessage` 提示区，并将收费项目相关提示改为写入该区域。
- `admin.html`：`renderDashboardRelated()` 按当前激活页面决定是否保留关联页筛选视图。
- `admin.html`：`studentFees()` 改为区分“未配置关联”和“已清空关联”。
- `scripts/validate-demo.mjs`：新增本次修正点的静态校验。
